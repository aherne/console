# Examples

The examples are split into source markup and rendered Unix terminal output:

- `input/` contains raw Lucinda Console markup.
- `output/` contains deterministic rendered output using LF line endings, Unicode drawing characters, width `80`, and plain-text mode.

The output files intentionally avoid ANSI escape bytes so they can be reviewed in any editor. They still reflect Unix-style terminal rendering; Windows legacy console behavior is not represented here because WSL is the supported Windows path.
